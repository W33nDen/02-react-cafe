# 02-react-cafe

Віджет відгуків Sip Happens Café. Vite + React + TypeScript, CSS Modules.

## Запуск

Потрібні Node.js 22.12+ (або 20.19+) та npm.

```bash
npm ci
npm run dev
```

## Перевірки

```bash
npm run build
npm run lint
npm run format:check
npx playwright install chromium
npm test
```

За наявності встановленого Chrome можна вказати шлях через змінну `CHROME_PATH`.
Тести запускають production preview автоматично. Перевіряють початковий стан,
усі категорії голосів, відсотки, повторні кліки, скидання, клавіатуру та мобільну ширину.

## Структура й логіка

- `src/components/App` зберігає єдиний стан `votes` через `useState<Votes>`.
- `handleVote` оновлює попередній стан функціонально, без мутації.
- `totalVotes` і `positiveRate` обчислюються при рендері, не зберігаються в стані.
- `CafeInfo` показує назву та опис.
- `VoteOptions` отримує типізовані колбеки `onVote`, `onReset` і прапорець `canReset`.
- `VoteStats` отримує `votes`, `totalVotes`, `positiveRate`.
- `Notification` показується замість статистики, коли голосів немає.
- Спільні `Votes` і `VoteType` містяться в `src/types/votes.ts`.
- Перезавантаження сторінки обнуляє голоси: збереження між сеансами завдання не вимагає.

Стилі компонентів узято з наданого викладачами репозиторію
https://github.com/goitacademy/react-cafe-styles
(коміт `c8a98fae130ee099d48389b7027deeec3e71ba46`), відформатовано Prettier
без зміни правил. Глобально підключено `modern-normalize`.

Код підготовлено за допомогою ШІ. Перед здачею варто переглянути реалізацію
та вміти пояснити стан, пропси, колбеки й умовний рендеринг.
